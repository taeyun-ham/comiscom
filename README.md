> 진심을 커밋하고, 내일을 배포한다  
> *Commit with heart, deliver tomorrow.*

---

## 📌 프로젝트 개요

소프트웨어 개발 프리랜서 **커밋이즈커밍**의 공식 회사 홈페이지입니다.  
회사 소개, 핵심 가치, 컬처북, 개발자 프로필, 문의 폼을 포함한 단일 페이지(SPA 구조) 정적 웹사이트입니다.

---

## ✅ 현재 구현된 기능

### 1. 네비게이션 헤더
- 스크롤 시 배경 블러/불투명도 변화
- 현재 섹션 활성 링크 하이라이트
- 모바일 햄버거 메뉴 (애니메이션 포함)

### 2. 히어로 섹션
- 터미널 스타일 타이핑 애니메이션 (3가지 커맨드 순환)
- 메인 슬로건 타이포그래피
- 배경 그리드 애니메이션 + 라디얼 글로우
- 터미널 마우스 패럴랙스 효과

### 3. About 섹션
- 회사 소개 텍스트
- 3가지 슬로건 카드 (한/영 병기)
- Git 커밋 로그 스타일 비주얼

### 4. 핵심 가치 (Values) 섹션
- 5가지 핵심 가치 카드 (hover 애니메이션 포함)
- Do/Don't 체크 리스트

### 5. 컬처북 (Culture) 섹션
- 탭 전환 UI (일할 때 / 함께할 때 / 실수했을 때)
- 자랑스러운 순간 / 경계하는 것 듀얼 카드
- 마감 인용문 블록

### 6. 개발자 프로필 섹션
- 아바타 + 재직 상태 표시
- 기술 스택 (Frontend / Backend / Cloud / Tools)
- 경력 타임라인
- 제공 서비스 그리드

### 7. Contact 섹션
- 연락처 정보 (이메일, GitHub, 위치)
- 문의 폼 (이름, 이메일, 문의유형, 메시지)
- 폼 전송 후 성공 메시지 애니메이션

### 8. 기타 UX
- 스크롤 탑 버튼
- 스크롤 진입 시 fade-in 애니메이션
- 반응형 (Desktop / Tablet / Mobile / Small Mobile)
- 브라우저 콘솔 브랜딩 메시지
