# 국토종주 자전거길

전용 주소: https://comiscom.kr/gpx/

17개 원본 GPX를 묶은 12개 기본 자전거길, 여러 파일 추가, 경로 표시 토글, 인증센터, 고도/경사도 그래프와 지도 위치 연동, 구간 분석을 제공합니다. 추가 파일은 브라우저에서만 처리합니다.

경사도: 선택한 거리 구간(기본 200m)의 고도 차 / 수평 거리 × 100. GPX 진행 방향 기준이며 측정 오차를 포함합니다. 고도 누락 구간과 분리 트랙을 이어 계산하지 않습니다. 누적 상승/하강은 3m 변화 기준으로 작은 흔들림을 줄인 추정값입니다.

루트 배포와 docs 폴더 배포를 모두 지원하도록 gpx/와 docs/gpx/에 동일한 파일을 둡니다. 수정 시 두 폴더를 동기화하세요. 기존 홈페이지 메뉴에는 링크를 추가하지 않았습니다. 이 페이지는 공개 정적 페이지이며 별도 접근 제한은 없습니다.

카카오 개발자 콘솔에서 지도 API 활성화 및 웹 도메인 https://comiscom.kr 등록을 확인하세요. www 주소도 사용한다면 https://www.comiscom.kr 역시 등록하세요. 로컬 지도 확인은 사용 중인 로컬 주소를 추가 등록해야 합니다. JavaScript 키는 브라우저에서 사용하는 공개 키이며 도메인 제한을 적용합니다.

로컬 확인: 프로젝트 루트에서 HTTP 서버를 실행한 뒤 /gpx/ 접속. 파일을 직접 여는 file:// 방식은 기본 경로 로딩을 지원하지 않습니다.

분할 경로 통합: 낙동강 1→2, 섬진강 2→1, 동해안 1→2→3(3번 방향 반전), 제주환상 1→2. 원본은 보존하며 통합 파일을 지도·그래프·다운로드에 사용합니다. 정확히 일치하는 연결점은 합치고 중복 인증센터를 제거합니다. 동해안 2·3 사이 약 28km 공백은 별도 트랙 구간으로 유지하며 계산에 포함하지 않습니다.
